05 · otevřené hranice

Architektura je připravená; některé důkazy teprve čekají na schválený běh.

Provider a veřejná kompatibilita pending

  • přesný snapshot aktuálních ISDS WSDL/XSD/rules a podporovaných metod;
  • reálný provider handshake, receipt semantics a conformance mimo offline fixtures.

Produkční persistence a provoz partial

  • deploy boundary je definovaná (Postgres / object store / durable queue); fixture zůstává SQLite/filesystem;
  • provider-specific queue consumer, failover a host-level deployment evidence nejsou součástí této slice.

Výkon a velké zprávy deferred

  • scénáře, limity a metriky pro ≥ 1 000 přijatých zpráv/min jsou připravené;
  • zatěžovací běh, burst, resumable upload a numerické výsledky nebyly provedeny.

Trust služby a právní rozhodnutí pending

  • kvalifikovaný timestamp/trust-service provider, certifikační handshake a rotace;
  • role controller/processor, retenční schedule a právní interpretace musí být schválené samostatně.
Další gate: udržet syntetický test boundary, doplnit provider/source rozhodnutí a teprve potom spustit izolované conformance a performance scénáře. Žádný výsledek této prezentace není compliance claim.
