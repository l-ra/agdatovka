# Source and requirements register

This file is the starting point for an evidence-backed requirements catalogue.
Each requirement will receive an ID and a traceability record containing:

- authoritative source URL, title, publisher, and access date;
- exact obligation or observed behavior;
- implementation interpretation, if any;
- acceptance scenario and evidence path;
- unresolved legal or interoperability questions.

Official requirements, observed behavior, and implementation decisions must be
kept separate. No compliance claim is valid without the corresponding source
and test evidence.
