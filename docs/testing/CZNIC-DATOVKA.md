# CZ.NIC Datovka compatibility plan

The open-source CZ.NIC Datovka client is the reference compatibility client.
The test environment will use synthetic accounts, certificates, trust stores,
endpoint profiles, message fixtures, and reproducible logs.

A separate fork of the desktop Datovka application will be maintained and
documented for execution against both AG Datovka 2 and the reference/test
system. Real accounts, real messages, and production credentials are out of
scope for the compatibility harness.
